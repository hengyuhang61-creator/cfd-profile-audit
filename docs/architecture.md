# Scope, policy and exit codes

The tool has **two** scoped features: (1) a one-dimensional support-aware CSV comparison, and (2) a bounded NASA/SWBLI teaching reproduction. There is no solver adapter, CFD file parser, database, plugin system, dashboard or distributed workflow.

**Supported input:** One row per unique coordinate, two selected numeric CSV columns. UTF-8 with an optional BOM; columns may be named using `--coordinate`, `--field`, `--computed-coordinate`, `--computed-field`. Coordinate rows must be strictly increasing unless `--sort` is explicitly set; duplicate coordinates and nonfinite values are errors even when sorting. Unit labels are checked only when supplied; convert computed coordinate units with the explicitly documented `--computed-coordinate-scale`, e.g. meters to millimeters via factor 1000, after confirming the physical convention. The application does **not** infer unit systems, align frames, average repeated measurements or guess the field transformation. Nonmatching field units always error. `--max-gap` is an optional segment-length cut-off; it cannot detect shocks or underresolution by itself.

**Interpretation:** `sample_coverage` is the fraction of reference nodes that lie on an admitted computed segment, including exact computed nodes. `interval_length_coverage` is the length of the supported subset of the reference coordinate extent, not an alternative sampling percentage. The overlap MAE/RMSE are in field units and use reference nodes equally (not length-integrated error). Full-domain eligibility is necessary, not sufficient, for scientific validation.

**Exit codes:** `0` = command operated normally (including deliberately failing `demo` and explicit overlap-only comparison); `1` = strict incomplete support or full coverage that exceeds specified `--max-rmse`; `2` = invalid data, no matched reference samples, or download/source-verification failure. JSON always contains the audit verdict when a comparison is evaluable; scripts must inspect both it and the exit code.

**Known limitations:** CSV header only, 1D only, no uncertainty propagation, floating-point coordinates exact after explicit scaling, no auto tolerance for near-matches, no physical consistency checks or uneven-sampling weight by default. `--max-gap` is in reference coordinate units. An interval can have 100% sample coverage but inadequate mesh resolution; nor is a sample's inclusion evidence that the reference measurement itself is valid.
